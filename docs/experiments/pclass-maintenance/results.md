N-class experiment report. Scoped observations do not grant landing authority.

## What changed

AGENTS routes to the existing verification skill. SKILL routes directly to one
P-class context recipe, which the optional feature map indexes. The recipe
separates global Issue delivery, local Session behavior, and feature maintenance.
It supplies a bounded working context and preserves unknown measurements.
System-v1 and production transitions remain unchanged. There is no new scheduler,
model launcher, or acceptance authority.

The skill-owned command recorder saves actual argv, output, exit, timing,
and file-argument byte counts and digests. It is not a complete native Session
trace. Independent source review found a long-argument snapshot failure.
The failure was reproduced before command launch, then fixed. The fix preserved
nonzero, timeout, and missing-executable outcomes. Six focused controls passed.

These mixed single trials do not establish lower context cost or faster reasoning. Bytes and captured process time are not model tokens or Session latency. Actual model provenance, complete native trace, tokens/window and compaction remain unknown. Instructions were explicitly supplied; automatic platform injection and storage security isolation were not tested. #39/#40's original gates are unchanged.

A small handoff carries the goal and scope, originating issue, executed subject,
evidence, unknowns, and next owner readback. Coordinator context does not become
consumer context. Expected answers and other arms stay outside consumers.
Full source and trace reads are conditional. The routing convention does not
guarantee context-window capacity.

## Maintenance and delivery

The feature used the pinned pstack maintain method
(ed3c/plugins@68836ddaf5697224520f1847d90cdb90ca8babaa). That method included
read-only source review, coordinator-owned live drives, evidence retention,
and correction of concrete drift. This was feature-scoped maintenance within
an implementation atom. It was not an upstream full-map clean/changed pass.
Runtime admission was live-driven separately and VERIFIED with zero scratch
residue. Full-map maintenance was incomplete. No admitted local Noodle/Codex
launcher was supplied for the existing bounded-execution feature.

N records observations. P remains guidance. Recorder and observer controls
support only their tested local rejection claims. Actual GitHub acceptance
and delivery readbacks provide their own provider evidence. Feature receipts
authorize no landing. [Issue 41](https://github.com/ed3c/soodles/issues/41)
and [PR 42](https://github.com/ed3c/soodles/pull/42) track final exact-head
acceptance and the separately pinned existing landing owner's merge, closure,
and Noodle reconciliation. The behavioral archive predates that production
delivery.
