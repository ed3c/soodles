# Candidate publication shortest-path task

Given a canonical Soodles acceptance receipt and the matching exact Noodle
publication claim, reach the one exact provider branch and pull request.

The consumer must not select or reconstruct repository, Issue, branch, base,
HEAD, tree, remote, title, body, push syntax, PR deduplication, or unknown-write
retry. Provider writes remain outside acceptance and landing authority.

The primary observable barrier is whether the repository exposes one P-class
route to one executable owner. A missing entry or guidance that requires
manual Git/provider construction counts as one barrier. The treatment must
reduce this barrier from one to zero while focused behavioral controls pass.
