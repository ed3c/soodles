# Issue 49: one P-class deletion was not retained

N-class observation for [Issue 49](https://github.com/ed3c/soodles/issues/49).
Baseline: `defc5f41153837f4db5ee0858fd03c9029523c6c`.
This report grants no acceptance or landing authority.

Six fresh native cloud consumers exercised three matched fixture cases. Captured
behavior supports scoped nonregression, but the deletion failed every pair's
prospective efficiency conditions. **AGENTS.md remains unchanged.** This is a
negative optimization result, not a repaired baseline defect or a universal claim.

## Change, controls and observations

The sole treatment deleted one 280-byte AGENTS bullet explaining the current
landing owner's next projection, missing inputs, historical commands and exact
request transport. SKILL.md and the supervised-delivery recipe retained those
responsibilities. Source, owner, recorder and other instruction bytes were common.
Task packets differed within each pair only by their assigned absolute directory.

The external observer was frozen before consumers started. Supervisor fixture
controls accepted legal behavior and rejected false resolution and omitted owner
observations. These controls were not model consumers. Consumers received neither
the expected result nor the author's conversation. Initial AGENTS/task reads were
explicitly requested; automatic instruction discovery was not tested.

| Case (baseline / treatment) | Captured instruction bytes | Captured stdout + stderr bytes | Observed behavior |
| --- | ---: | ---: | --- |
| Pending offer (a / b) | 26,372 / 32,162 | 39,160 / 44,558 | Both preserve checkpoint and require fresh owner/provider readback; no request emitted |
| Missing commit recovery (d / c) | 26,372 / 32,162 | 40,492 / 42,875 | Both first receive actual owner refusal, preserve checkpoint, then use supplemental commit readback to prepare closure |
| Foreign identity (e / f) | 26,372 / 26,092 | 35,604 / 36,295 | Both receive actual identity refusal, preserve checkpoint and require supervisor correction |

Independent review checked all 53 captured command records, stdout/stderr hashes,
explicit cat output against bound source bytes, original and corrected recovery
inputs, owner responses and final state. Treatment b/c also read the 6,070-byte
recovery recipe, outweighing the removed 280 bytes. This observed route difference
does not prove the deletion caused that choice.

There were no repeated instruction documents. Audited directory enumeration
counts were a=1, b=1, c=0, d=1, e=0, f=1. The fixed observer's search counter missed
d's Python rglob and f's ls -R; independent review preserves those extra observations.
The judge was not changed to make the candidate pass.

- One matched pair per case supports only these captured outcomes. No statistical
  population equivalence, general cost reduction or internal decision count.
- Measured bytes are explicit instruction cat reads and captured subprocess
  stdout/stderr. They are not input tokens or total rendered platform context.
- Consumer-recorded commands are not full native Session exports. Native model
  provenance, hidden activity, effective window occupancy and compaction remain
  unknown. No forbidden operations were visible in the inspected records.
- A neutral sentence requiring the initial owner read before supplemental inputs
  was appended equally before freeze and all launches. selection.json retains
  stale task hashes from before that amendment; freeze.json binds actual tasks.
  This discrepancy is disclosed, not silently repaired.
- The recovery cases permit owner checkpoint transitions; all claims remain
  identical. Their terminal close_pending state is not provider closure.
- This is one feature comparison, not a full maintain-map pass. No skill or owner
  code changed. The experiment does not establish a Noodle/Codex production order.
