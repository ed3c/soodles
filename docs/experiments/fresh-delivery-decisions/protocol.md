# Frozen first-decision protocol

Scope: assess current instruction compatibility at one delivery handoff, not
autonomous implementation, actual provider transport or global hill climb.
Origin owns the N-class correction to #97 and this experiment together.

Use two fresh native consumers for each of four disposable fixtures (eight
baseline responses). Use `fork_turns: none`, no model override, separate evidence
directories and the same task and instruction packet. Do not give consumers
this protocol, the observer, historical diagnosis, other outputs or expected
answers. Record the exact launch message, returned final text and initial
recorded read. Requested configuration is known; observed model identity,
complete platform transcript, hidden reads, tokens and compaction are unknown.
No retry or dropped response: a missing/malformed response is inconclusive.

Before launch freeze task, context packet, fixtures, observer and this protocol
in the originating Issue. Context contains full AGENTS, verify-soodles SKILL,
supervised-delivery recipe and the complete LANDING.SUPERVISED.001 section.
It is the complete selected delivery context, not every repository instruction.
Pin source file digests and provider/local tree identities separately.

Cases: A has an unmerged candidate with a missing required artifact; B has an
unmerged candidate whose prompt differs from the manifest; C has complete
candidate evidence and a prepared current owner; D has a resolved prior atom
and a new defect first discovered after that merge. A/B accept same-PR revision;
C accepts current owner consumption; D accepts a new atom. Check subject
identity and owner as well as action. Fixture process outputs must establish
these states; no candidate-authored PASS boolean supplies the expected result.

Score only explicit structured choices and the immediate `next.owner`, not a
later resumed operation's owner. Count one mismatch per response, not
hidden reasoning or command cost. Missing identity, invalid JSON or an unknown
action is UNSCORABLE, not a failure inferred from absence. A legitimate stop
requires a missing case prerequisite, so fully supplied cases do not count an
invented prerequisite as zero. Preserve reason text for independent review.
Sensitivity controls must reject pre-merge split, direct/incorrect next action,
wrong subject and applying same-PR correction after a post-merge discovery;
malformed input must remain UNSCORABLE. These are planted detector controls,
not baseline observations.

If baseline has zero specified violations: no P-class edit and no treatment;
deliver N-class correction and bounded baseline only. If nonzero: retain this
as discovery, freeze a minimal correction and matched follow-up protocol before
additional fresh runs; do not silently change this observer. A proper improvement
claim requires matched exposure and no legal-case regression. Unknown model
provenance limits any model-specific claim. Equal results are not hill climb.

Independent replay uses a fresh reviewer reading frozen inputs, raw final text,
recorded-read evidence and observer source. It rederives results and audits the
claim boundary; running the author observer alone is not independent telemetry.
A matching structured choice is not by itself a legal decision: the independent
reviewer must check its reason for contradictions. A contradictory or unassessable
reason blocks the legality claim even when the tuple matches; the deterministic
observer reports MATCHING_CHOICE only. D's later discovery is a stipulated
scenario premise, not a defect demonstrated by the real owner's resolved output.
All receipts are non-authorizing. Actual delivery is separately gated through
one PR, exact committed byte validation, runtime, quality and external landing
owner/provider readbacks. No failed head is rerun unchanged or merged partially.
