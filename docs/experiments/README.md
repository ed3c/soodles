# Read historical experiment records

These records describe the source, carrier and inputs selected for each experiment.
They do not define the current workflow or grant execution authority.
Read the current repository entry and the selected owner's instructions for active work.

The documentation rewrite changes explanatory prose only. It preserves historical
conclusions, limitations and measurements. A statement such as "current", "pending"
or "next" describes the stage recorded in that article. It does not report today's state.

Raw logs, receipts, captured responses, frozen instructions and selected experimental
protocols retain their original bytes. Commands and evidence blocks inside revised
articles also retain their original bytes. Do not execute historical commands as
current continuations.

Historical manifests retain their recorded digests. They refer to the original
artifacts, not to the revised explanations. To check an original article against
its recorded digest, read it at the
[version before the documentation rewrite](https://github.com/ed3c/soodles/tree/f5df50628e5289788f4185fb9f10a8b15dd23c69/docs/experiments).
If a receipt selects another source ref or external file, use that exact selection.
Do not update an old receipt or manifest to match revised prose.

The rewrite uses ASD-STE100 writing principles: short sentences, explicit actors,
conditions before actions and consistent terms. It does not claim formal
ASD-STE100 compliance or a measured compliance percentage.
